# Munchy's Kitchen — 3D Restaurant Website Concept

A responsive React + Tailwind CSS + Three.js restaurant website concept.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP and open the folder in VS Code.
3. Open the terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

To create a production build:

```bash
npm run build
```

## Before presenting this to the restaurant

This is a demonstration concept, not an official Munchy's Kitchen website.

Update `src/App.jsx`:
- Replace `PHONE_NUMBER` with the restaurant's verified WhatsApp number in international format, digits only (example format: `2348012345678`).
- Confirm the current address and opening hours with the restaurant.
- Replace illustrative food images with approved restaurant photographs.
- Confirm the actual menu, descriptions, availability, portion sizes and prices.
- Confirm delivery areas, fees, pickup process and order handling.

The current menu names are examples based on publicly associated dishes; descriptions, availability and prices are not verified. Prices are deliberately shown as "Price on request". Checkout is a WhatsApp message hand-off only. No payment processing, order database, delivery tracking or restaurant admin dashboard is included.

## Technology

- React + Vite
- Tailwind CSS v4
- Three.js for the interactive 3D hero visual
- Lucide React icons
